# LLD: IPC Contract Specification

## 1. Overview & Threat Model

The Electron IPC bridge is a critical security boundary separating the sandboxed React renderer from the privileged Node.js main process.
- **Rule 1**: Zero Node.js primitives (`child_process`, `fs`, `net`, `electron`) may be directly accessible in the renderer.
- **Rule 2**: Every IPC channel must have strict parameter validation and return structured, type-safe response contracts.
- **Rule 3**: All communications use `ipcRenderer.invoke` (request-response pattern) or unidirectional `ipcRenderer.on` (main-to-renderer push notifications).

## 2. API Contract: `window.veAPI`

Exposed via `contextBridge.exposeInMainWorld("veAPI", ...)` in `app/preload/preload.cts`:

```typescript
export interface VeDesktopAPI {
  // 1. Command Execution & Intent
  runCommand(request: CommandRequest): Promise<CommandResponse>;
  confirmAction(actionId: string, approved: boolean): Promise<void>;

  // 2. Proactive Suggestions & State
  onSuggestionUpdate(callback: (suggestions: ProactiveSuggestion[]) => void): () => void;
  onExecutionStatus(callback: (status: ExecutionProgressEvent) => void): () => void;

  // 3. User Data & Preferences (Local Only)
  getPreferences(): Promise<UserPreferences>;
  updatePreferences(patch: Partial<UserPreferences>): Promise<void>;
  
  // 4. Memory & Note Management
  listMemories(): Promise<MemoryItem[]>;
  addMemory(text: string): Promise<MemoryItem>;
  deleteMemory(id: string): Promise<void>;

  // 5. Contacts Management
  listContacts(): Promise<ContactItem[]>;
  addContact(name: string, phone: string): Promise<ContactItem>;
  deleteContact(id: string): Promise<void>;

  // 6. Privacy & Learning Controls
  getLearningStats(): Promise<LearningStats>;
  clearLocalBehaviorData(): Promise<void>;
  setFederationOptIn(optIn: boolean): Promise<void>;

  // 7. Window Controls
  closePopup(): Promise<void>;
}
```

## 3. Data Transfer Objects (DTOs)

### Command Execution Payloads
```typescript
export interface CommandRequest {
  id: string;                      // UUIDv4 generated by renderer
  text: string;                    // Raw input text from user
  source: "keyboard" | "voice";    // Input modality
  clientTimestamp: number;         // Unix timestamp ms
}

export type CommandStatus = 
  | "success"
  | "clarification_needed"
  | "confirmation_required"
  | "unsupported"
  | "error";

export interface CommandResponse {
  requestId: string;
  status: CommandStatus;
  displayText: string;             // Human-readable message shown in bubble
  skillId?: string;                // e.g., "open_app", "web_search"
  executionDurationMs?: number;
  
  // Populated when status === "confirmation_required"
  pendingAction?: {
    actionId: string;
    riskTier: 1 | 2 | 3;
    title: string;
    description: string;
    impactSummary: string;
  };

  // Populated when status === "clarification_needed"
  clarification?: {
    question: string;
    suggestedOptions: string[];
  };

  // Populated when status === "error"
  error?: {
    code: string;
    message: string;
  };
}
```

### Proactive Suggestions
```typescript
export interface ProactiveSuggestion {
  id: string;
  actionCommand: string;           // Canonical command string e.g. "Open VS Code"
  skillId: string;
  confidence: number;              // 0.00 to 1.00
  reason: string;                  // e.g. "Usually opened around 9:00 AM on weekdays"
  expiresAt: number;               // Unix timestamp ms
}
```

## 4. Main Process IPC Handler Registry

The main process registers listeners via `ipcMain.handle`:

```typescript
// app/main/ipcHandlers.ts
import { ipcMain } from "electron";

export function registerIpcHandlers(coordinator: AssistantCoordinator) {
  ipcMain.handle("ve:runCommand", async (_, req: CommandRequest): Promise<CommandResponse> => {
    validateCommandRequest(req);
    return await coordinator.handleUserInput(req);
  });

  ipcMain.handle("ve:confirmAction", async (_, actionId: string, approved: boolean): Promise<void> => {
    validateString(actionId);
    await coordinator.resolvePendingConfirmation(actionId, approved);
  });

  ipcMain.handle("ve:clearBehaviorData", async (): Promise<void> => {
    await coordinator.clearBehaviorStore();
  });
}
```
